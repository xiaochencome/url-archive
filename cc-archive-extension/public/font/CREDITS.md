# 随扩展分发的字体

本目录的中文字体只是「显示字体」选项，用户可以在设置里换成系统字体。

| 文件 | 字体 | 用途 |
|------|------|------|
| `LongCang.woff2` | Long Cang（龙藏体） | 手写风选项 |
| `MaShanZheng.woff2` | Ma Shan Zheng（马善政毛笔楷书） | 毛笔风选项 |
| `ZCOOLKuaiLe.woff2` / `ZCOOLQingKe.woff2` / `ZCOOLXiaoWei.woff2` | 站酷快乐体 / 站酷庆科黄油体 / 站酷小薇体 | 标题风选项 |
| `SmileySans-Oblique.woff2` | 得意黑 Smiley Sans | 斜体黑选项 |

这些字体都通过 Google Fonts 公开分发，许可证以各自官方仓库为准（多为 SIL Open Font License 1.1）。

**发布 / 再分发前请补齐：**把每个字体对应的许可证全文（`OFL.txt` 等）放进本目录并在此表格里注明，OFL 要求许可证随字体一起分发。本仓库没有自行主张任何字体版权。
